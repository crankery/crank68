# VERA adapter — inactive legacy add-on

This board experiment is paused in favor of the [Instore keyboard and SD
board](../../Instore/). The KiCad design and image remain here for
reference. Its `$E080` keyboard interface is not compatible with the current
[Instore keyboard AVR firmware](../../../src/keyboard_avr/README.md).

The historical VERA software is documented in [src/vera](../../../src/vera/README.md).
